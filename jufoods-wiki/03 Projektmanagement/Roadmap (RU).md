## Модуль 1: Каталог

**Цель:** Полностью доделать каталог продуктов и сделать его консистентным.

### Доработка логики тортов
- [ ] Полностью перевести страницу деталей на `torten_designs` (убрать фолбэк на `products`)
- [ ] Правильно использовать связку Design-Flavour (`design_flavour`) на странице деталей
- [ ] Корзина: хранить только Design-ID + опциональный выбор начинки
- [ ] Привести TypeScript-типы для новой системы тортов в порядок

### Переработка категорий
- [ ] Пересмотреть навигацию по категориям (вкладки в шапке / сайдбар / дропдаун)
- [ ] Улучшить UX фильтрации по подкатегориям
- [ ] Решить: `products/page.tsx` (сейчас только редирект) — отдельная страница или оставить на главной

### Другие продукты — отдельное представление
- [ ] Десерты, Cookies, Чизкейки, Макаруны: собственный макет деталей (без выбора начинки)
- [ ] Дополнить данные в БД (изображения, описания)
- [ ] Обеспечить консистентное отображение тортов и остальных продуктов
